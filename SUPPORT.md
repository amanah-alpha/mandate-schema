# Support

## How to get help

1. **Documentation first:** `README.md`, `schema/mandate.schema.json`
   (self-describing), and the tests under `tests/` are the executable
   specification.
2. **Questions & usage:** open a GitHub Discussion or Issue with the
   `question` label.
3. **Bugs:** open an Issue using the bug template — include the minimal
   reproducing payload.
4. **Security issues:** Private Vulnerability Reporting only (see
   SECURITY.md). Never public issues.

## What this project does NOT support

- Sharia rulings, halal/haram determinations or regulatory advice — the
  schema is governance metadata structure only.
- Production deployments of the amanah-alpha reference engine (see that
  repository's boundaries).

## Response expectations

This is a maintained open-source contract repository: issues are triaged
weekly; security reports take priority over everything else.
