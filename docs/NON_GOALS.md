# Non-Goals

This repository does not attempt to define:

- a universal policy language;
- an executable compliance language;
- an authorization model;
- a financial transaction protocol;
- a lifecycle event standard;
- the legal validity of mandates;
- Sharia rulings;
- regulator approval;
- digital signatures; or
- production policy evaluation.

It also does not contain institution-specific mandates, approved rule libraries, methodology mappings, customer data, or production configuration.

The schema records governance provenance and lifecycle metadata plus references to controls. Those references do not specify executable rule behavior.
